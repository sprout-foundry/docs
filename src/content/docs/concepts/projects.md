A **project** is one thing you're building: an app, a site, a tool. Every
project is a real **git repository** with its full history — every change
Sprout makes is recorded, so nothing is a black box and nothing is lost.

## Where the code lives

- **Projects you start in Sprout** live in a repository Sprout hosts for you.
- **Projects from your own repository** (GitHub, GitLab or Codeberg) stay in
  that repository: tasks work on it as it is on its remote. See
  [Connect a git host](/guides/connect-git/).

## Views of a project

- **Tasks** — describe a change and follow the work. Builders see a list to
  work through; developers can switch to the board.
- **Preview** — your app as it is right now.
- **Put it online** — give the app its own address and make it live. See
  [Put your app online](/guides/put-it-online/).
- **Developer workspace** — the code itself, in the browser, with the agent
  built in.
